# BPGV Tier-3 validation harness (Package F)

Implements the overfit-controls gate referenced by the Tier-3 plan:

| Module | Purpose | Literature |
|---|---|---|
| `dsr.py` | Deflated Sharpe at a given N-trials | Bailey & Lopez de Prado 2014 |
| `harvey_liu.py` | Multiple-testing haircuts (Bonferroni / Holm / BHY) | Harvey-Liu-Zhu 2016 |
| `politis_romano.py` | Stationary block bootstrap + Ledoit-Wolf Sharpe test | Politis-Romano 1994, Ledoit-Wolf 2008 |
| `cpcv.py` | Combinatorial Purged K-Fold splitter | Lopez de Prado 2018 Ch. 12 |
| `benchmarks.py` | SPY / 60-40 / EW SPY-TLT-GLD return loader | — |
| `runner.py` | Top-level: load equity → compute returns → run all tests → emit Markdown | — |

## Install

```bash
pip install -r requirements.txt
```

(Adds scipy, numpy, pandas, psycopg2-binary if not present.)

## Typical run

After a full backtest completes:

```bash
# 1) Equity curve is already in Postgres — pass the run id
python -m tools.validation.runner --run-id BPGV_ROTATION_20260421_XXXXXX_YYY

# OR 2) Export equity to CSV first and point at the file
python -m tools.validation.runner --equity-csv /path/to/equity_curve.csv
```

The runner writes `reports/validation_<label>.md` and prints a summary.

## Gate check

The report ends with a pass/fail list:

- **DSR (N=30) ≥ 0.95** — deflated Sharpe clears Bailey-LdP threshold
- **HL Bonferroni p < 0.05 (N=30)** — survives Harvey-Liu family correction
- **Beats EW SPY/TLT/GLD at LW one-sided 5 %** — genuinely adds alpha vs the
  zero-parameter benchmark

All three must pass for a Package to clear its phase gate per the Tier-3
plan. If any fails, the change is reverted at config level.

## Notes

- The Ledoit-Wolf test is one-sided (strategy > benchmark). The two-sided
  p-value is reported for completeness.
- Block length defaults to Politis-White 2004 automatic selector; override
  via `--n-boot` and the `block_length` keyword in the module API.
- CPCV folds are generated by `cpcv.py` but the actual CV loop requires
  re-running the C++ backtest over each fold's date range — left to a
  follow-up script (Package F sub-task).
